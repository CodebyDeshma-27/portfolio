# Portfolio

Build a premium engineering portfolio website for Deshma Udayakumar.

This website is NOT a resume website.

It is NOT a personal blog.

It is NOT a startup landing page.

It should feel like the personal workspace of a software engineer who is passionate about Full Stack Development, Security Engineering, Cloud and DevOps.

The overall design should communicate professionalism, technical credibility, simplicity and attention to detail.

When someone opens the portfolio, they should immediately understand:

• Who I am

• What I specialize in

• What I have built

• What technologies I work with

• Why I would be a strong engineering hire

The portfolio should let the work speak for itself instead of relying on self-promotional statements.
